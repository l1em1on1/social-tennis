# Court availability via ClubSpark API deferred to a later phase

`features.md`'s "show court availability" (referencing the ITF ClubSpark docs) is a real external API integration, not a v1 requirement. v1 substitutes manual court entry by the league manager.

**Investigated**: the referenced ITF ClubSpark docs (`stg-itf-docs.clubspark.io/api-docs/`) are actually the ITF World Tennis Number (WTN) rankings/GraphQL API — players, rankings, match-ups — not court booking or availability at all, and they list no public registration process. A genuinely public, unauthenticated feed does exist (`api.clubspark.uk/odi/public/courses`, OpenActive-compliant, documented at `github.com/LawnTennisAssociation/opendata`), but it covers programmed *courses* at a venue, not general ad-hoc court-booking availability. So the original doc's reference doesn't actually support this feature as described — whatever real court-availability integration exists (if any) has not been identified yet. Revisit by looking specifically for a club-level booking-system API (e.g. the club's own court-booking software) rather than assuming ClubSpark/ITF covers it, alongside ADR-0004's login-with-ClubSpark investigation since both touch the same vendor relationship.
