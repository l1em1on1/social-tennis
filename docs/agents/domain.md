# Domain docs

This repo has one context: `CONTEXT.md` (the glossary) and `docs/adr/` at the root.

- **Before exploring** an area, read `CONTEXT.md` and the ADRs that touch it.
- **Name domain concepts** with `CONTEXT.md`'s terms, in issues, proposals, hypotheses and test names, not the synonyms it lists under _Avoid_. A concept it lacks is a gap: note it for `/domain-modeling`.
- **Flag an ADR conflict** in the output itself: _Contradicts ADR-0007 (…), but worth reopening because…_
