# Triage labels

The skills' five triage roles, and this repo's label for each (the same strings):

| Role / label | Meaning |
|---|---|
| `needs-triage` | The maintainer needs to evaluate it |
| `needs-info` | Waiting on the reporter |
| `ready-for-agent` | Fully specified, ready for an agent |
| `ready-for-human` | Needs a person to implement it |
| `wontfix` | Won't be actioned |
