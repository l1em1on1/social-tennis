# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability** (GitHub's private vulnerability reporting).
3. Describe what you found, how to reproduce it, and what it affects.

Only the maintainers see the report. You'll get an answer within a week, and we'll agree a disclosure date with you once a fix is out.

## Scope

In scope: this repository's code, its CI workflows and infrastructure definitions, and the hosted app built from it.

Out of scope: third-party services the app runs on (Azure, Neon, Cloudflare, GitHub). Report those to their owners.

## Supported versions

Only the latest commit on `main`, which is what the hosted app runs.
